# Agent instructions

[CONTRIBUTING.md](CONTRIBUTING.md) has the commands, checks, and release steps for this repository. Follow it for every change.

## Thank outside contributors

When a pull request from a fork merges, comment on it to thank the author by handle. Say what the change fixed, and link any follow-up pull requests that its review led to. When you close one without merging, thank the author as well and say why it did not land.

The release entry in `CHANGES.md` also credits the author by handle and links the pull request, as the 0.9.80 entry does for @mshk and #245.
