This Copilot home has no pstack model sheet yet, and pstack ships no default Copilot models. When this session first invokes a skill that dispatches on role models (`arena`, `architect`, `interrogate`, `how`, `reflect`, `swarm`, `why`), load `setup-pstack` with the `skill` tool and finish it before that skill's first step, even for a small question. It asks the user each model question with `ask_user` and writes the sheet that later sessions reuse. It never picks a model the user has not chosen, so when `ask_user` is not available it writes no sheet, and the roles run on the session's model.
