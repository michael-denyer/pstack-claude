On GitHub Copilot, load pstack skills by their bare names through the `skill` tool (`poteto-mode`, `tdd`, `architect`, not `pstack:poteto-mode`); the plugin's agents keep the prefix (`pstack:poteto-agent`, `pstack:comment-sicko`). Copilot lists only part of a large plugin's skills in its prompt; every pstack skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a pstack skill names through `references/copilot-tools.md` in the `poteto-mode` skill directory. pstack ships no default Copilot models. A skill that dispatches on role models (`arena`, `architect`, `interrogate`, `how`, `reflect`, `swarm`, `why`) takes them from the user's saved pstack model choices, which the plugin hook adds to the end of this block when the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/pstack-models.md`, exists. Do not `view` the sheet while those choices are in context. It sits outside the workspace, so reading it asks for path access. After `setup-pstack` writes the sheet in this session, use the values it just wrote.
